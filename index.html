LIMITATIONS & PRIVACY

What this app does not claim

01 / No fake output

Boş, hata veren ya da erişilemeyen API sonuçları açıkça hata olarak gösterilir.

02 / No private Telegram data

Private messages, phone numbers, hidden data or member lists are not enumerated.

03 / No unlimited quota

Public services can rate-limit, block or change access. No free API means infinite requests.

04 / Local-first encrypted sync

History stays in this browser unless you pair devices. Optional sync encrypts data client-side; the server stores ciphertext and needs persistent storage.

DEVICE PAIRING

Encrypted sync.

No account. One pairing code. Automatic sync after connection.

◇
End-to-end encrypted history

Tarayıcı AES-GCM ile şifreler. Sunucu yalnızca şifreli veriyi saklar; pairing code anahtarı içerir.

AES-GCM
Local-only modeCihazlar arası sync henüz bağlanmadı.
How it works
  1. İlk cihazda bir pairing code oluştur.
  2. Kodu güvenli şekilde ikinci cihaza kopyala ve aynı HTTPS siteyi aç.
  3. İkinci cihazda Connect / Sync seç. Sonraki sorgu geçmişi otomatik eşitlenir.

Code'u bilen kişi geçmişini okuyabilir. Code'u paylaşma. Sunucu verisi için kalıcı disk gerekir; ücretsiz hostlar veriyi silebilir. Tek cihazda kullanım için sync kurman gerekmez.
